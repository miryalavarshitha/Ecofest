# 🍽️ EcoFeast — Eat Smart. Live Green

## 🔍 About the Project

EcoFeast is a sustainability-focused smart dining platform designed to modernize restaurant services while promoting eco-friendly practices. The platform integrates **online food ordering**, **table reservation**, **event booking**, **food donation**, and an **AI-powered chatbot (EcoBot)** into a single full-stack web application.

The project aims to reduce food waste, improve dining convenience, and encourage sustainable food management through digital solutions and reward-based participation.

---

## 🎯 Key Features and Use Cases

* ✅ Online food ordering and cart management
* ✅ Table reservation and booking system
* ✅ Event reservation and management
* ✅ Food donation system to reduce food waste
* ✅ Eco-rewards system for sustainable participation
* ✅ AI chatbot support for complaints and food recommendations
* ✅ Responsive and user-friendly web interface

---

## 🤖 EcoBot Chatbot

**EcoBot** is an AI-powered chatbot integrated into the platform that helps users:

* 🍱 Get personalized food recommendations
* ⚠️ Register and manage complaints
* 📋 Navigate restaurant services and reservations
* 💬 Answer user queries interactively
* 🌱 Promote eco-friendly dining practices
